## 📌 Sobre

Este repositório contém uma coleção de **cheatsheets** (guias rápidos) essenciais para desenvolvedores. Aqui você encontrará comandos básicos e avançados para diversas tecnologias, organizados de maneira prática para facilitar a consulta no dia a dia.

Atualmente, o repositório possui os seguintes cheatsheets:

-   🐳 [**Docker**](./cheatsheets/pt-br/docker.md) - Comandos essenciais para gerenciamento de contêineres.
-   🌐 [**Nginx**](./cheatsheets/pt-br/nginx.md) - Comandos para controle do servidor web Nginx.
-   ⚡ [**Quick Commands**](./cheatsheets/pt-br/quick_commands.md) - Coleção de comandos úteis para diversas ferramentas.

Cada cheatsheet possui versões em **português (pt-br)** e **inglês (en)**.

cheatsheets/

## 🚀 Como Usar

Você pode navegar pelos arquivos diretamente no GitHub ou cloná-los para o seu computador:

```bash
git clone https://github.com/seu-usuario/cheatsheets.git
```

Acesse a versão desejada:

```bash
cd cheatsheets/pt-br  # Para português
# ou
cd cheatsheets/en  # Para inglês
```

Abra o arquivo desejado em seu editor de texto favorito.
